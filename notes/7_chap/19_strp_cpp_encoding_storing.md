    В C++ существует несколько способов записать символ, например, если мы
    запишем следующим образом:
    ```cpp
    #include <iostream>

    int main()
    {
    	auto symb = 'k';
    	return 0;
    }
    ```
    То переменная symb типа char (можно в gdb спросить ```ptype symb```) и
    хранится в памяти как 0x6b что соответствует нужному символу в таблице
    ASCII.

    Если запишем следующим образом:

    ```cpp
    auto symb = L'k';
    ```
    То переменная будет иметь тип wchar_t и в памяти хранится аналогично 0x6b.
    При этом размер переменных равен 4 (```sizeof(symb)```). Это так называемые
    широкие(многобайтовые) символы[1].

    Если запишем следующим образом:
    ```cpp
    auto symb = u8'k';
    ```
    То переменная будет иметь тип char, в памяти хранится 0x6b, а размер - 1.
    Это соответствует основным символам Unicode, которые являются ASCII-
    символами, которые помещаются в один байт.

    Если запишем следующим образом:
    ```cpp
    auto symb = u'k';
    ```
    То переменная будет иметь тип char16_t, в памяти хранится 0x6b, а размер -
    2. Это соответствует расширенному набору Unicode символов, которые
    помещаются в два байта.

    Если запишем следующим образом:
    ```cpp
    auto symb = U'k';
    ```
    То переменная будет иметь тип char32_t, в памяти хранится 0x6b, размер - 4.
    Это соответствует полному 4 байтному набору Unicode символов.
    Пока все символы помещаются, но мы верим, что это ещё не конец..
