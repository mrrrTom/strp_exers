$cat array_is_pointer
    Массивы в C++ штука весьма простая и эффективная. Как проще всего
    реализовать коллекцию объектов? Ну, просто сложить их рядом и указать на
    первый. Собственно, именно так и поступили разработчики языка. То есть,
    когда мы объявляем и определяем массив, то дальше используем имя этого
    массива как указатель на первый элемент. При чём со стороны массива у нас
    нет ограничений - мы можем итерироваться хоть за пределы массива. Другой
    вопрос, что в таком случае словим неопределённое поведение, то есть
    неопределённое стандартом поведение, которое может трагическим образом
    меняться от реализации к реализации.
    Например, следующий код спокойно выполняется на моём окружении:
    ```cpp
    
    #include <iostream>

    int main()
    {
    	int arr[1] = { 8 };
	    for (int i = -5; i < 6; ++i) {
		    std::cout << arr[i] << std::endl;
	    }

	    return 0;
    }
    ```

    На выходе имею какой-то набор значений, то есть мы сходили в какую область
    памяти рядом с массивом +-(n * размер int) и без проблем получили оттуда
    значение. При удачных звёздах можно не только прочитать, но и записать
    что-то в какие-то соседние области памяти, а иногда даже угадать, куда оно
    попадёт, например, при запуске кода на моём окружении я получаю попадания
    данных в соседние массивы:

    ```cpp
    #include <iostream>

    int main()
    {
    	int arr0 [10];
    	int arr[1] = { 8 };
    	int arr3 [10];
    	for (int i = -5; i < 5; ++i) {
    		arr[i] = i;
	    	std::cout << arr[i] << std::endl;
	    }

	    for (int i = 0; i < 10; ++i) {
	    	std::cout << "arr0: " << arr0[i] << std::endl;
	    	std::cout << "arr3:" << arr3[i] << std::endl;
	    }

	    std::cout << "finished";
	    return 0;
    }
    ```

    В прямом смысле массив в C++ - это даже не класс, например, вы не сможете  
    объявить в одной области видимости следующие функции из-за совпадения их
    сигнатур за счёт неявного преобразования int[] -> int*
    ```cpp
    int sum(int input[1]) {
	    return input[0];
    }

    int sum(int* input) {
	    return *input;
    }
    ```

    Из-за такого неявного преобразования нельзя написать функцию, в которую
    массив передаётся по значению. Однако есть ситуации, когда проявляется
    неравносильность type[] и type*. Например:

    ```cpp
	char* symbs = "hello";
	symbs[0] = 'a';
	std::cout << symbs;
    ```
    В этом коде есть ошибка, которая связана с попыткой записи в память, в
    которой хранится неизменяемая строка. А если компилятор настроен, то ошибку
    мы увидим еще при попытке определить массив. Так как мы присваиваем
    неконстнатному указателю указатель на неизменяемое значение. Если же мы код
    напишем вот таким образом:
    ```cpp
	char symbs[] = "hello";
	symbs[0] = 'a';
	std::cout << symbs;
    ```
    То избежим таких ошибок, потому что при инициализации массива значения
    из константной строки будут просто скопированы. Таким образом массивы и
    указатели - это одно и тоже, но не всегда.
