   И так, создадим Hello World! на C++.
   1. Стандартной точкой входа в программу является функция int main() {}
   2. В теле этой самой функции нужно вызывать функцию печати, передав ей строку "Hello, world!"
   3. Чтобы распечатать текст в терминал, нам требуется передать в стандартный поток вывода нашу строчку. Используем оператор вставки в поток "<<"
   4. Чтобы обратиться к стандартному потоку вывода, нам потребуется поток std::cout, объявленный в заголовочном файле iostream. Чтобы использовать этот файл добавим его с помощью директивы #include <iostream>

   #include <iostream>

   int main()
   {
        std::cout << "Hello, World!";
   }

   Чтобы создать исполняемый файл создадим файл hello.cpp, в который запишем подготовленный выше код. Этот файл требуется скомпилировать, получив объектный файл, с помощью команды 'g++ -c hello.cpp'. В рабочей директории появится файл hello.o, этот файл содержит машинный код и метаданные, необходимые для выполнения программы. 
   Теперь из объектного файла с помощью линкера нужно собрать исполняемый файл 'g++ -o a.out hello.o', в рабочей директории появится файл a.out, запустив который мы увидим желанное приветствие.
