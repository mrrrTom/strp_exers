    В C++, как мы обсудили ранее существует возможность выполнять параллельные задачи. Параллельные задачи мы создавали с помщью ```thread```.
    По сути мы заставили создать некий поток, в который и передали наше задание. Создание потока - это достаточно тяжеловесная операция, но главное, что она не учитывает возможности машины.
    Чтобы с помощью непосредственного использования потоков эффективнее управлять параллельным выполнением, нужно использовать дополнительные средства, например, ```boost::thread::hardware_concurrency()```.
    C++ позволяет использовать и другие подходы к параллелизму, например, модель асинхронных задач реализуется с помощью ключевого слова ```async(...)```.
    Выделяя асинхронные задачи, программист выделяет те задачи, которые МОГУТ быть выполнены параллельно, однако оставляет за системой решение, что и как запускать параллельно.
    ```async``` позволяет отделить выполнение задачи и возврат значения после её выполнения, а так же и то и другое от реального выполнения задачи.
    Отделение выполнения от возврата происходит с помощью ```promise``` и ```future```. Собственно ```async()``` возвращает ```future```, и абстрагирует от нас явное использование ```promise```, например:

```cpp
    #include <vector>
    #include <iostream>
    #include <future>
    #include <numeric>
    using namespace std;

    vector<int> nums;

    int accum(int *beg, int *end)
    {
    	return accumulate(beg, end, 0);
    }

    int main() 
    {
    	for(int i = 0; i <= 1000; i++)
    	{
    		nums.push_back(i+1);
    	}

	    auto f1 = async(accum, &nums[0], &nums[500]);
	    auto f2 = async(accum, &nums[500], &nums[1000]);

	    cout << (f1.get() + f2.get());
	    return 0;
    }
```
