    Некоторые классы используют выделяют память. Она им может понадобиться, например, чтобы хранить неопределённое количество элементов.
    Например, контейнер, который будет хранить коллекцию чего-то, что нам нужно выделил в конструкторе память для этих элементов с помощью операции new().
    Возникает проблема, где же нам эту память освободить? Если бы мы говорили про C#, то там при уничтожении объекта сборщик мусора без нашего участия эту память бы осводил бы.
    В классе можно определить метод, который вызывается при разрушении объекта - деструктор. Вот в нём принято память и освобождать:
    class Container {
        private:
            int* elements;
        public:
            Container(int size) : elements {new int[s]} {
                for (int i = 0; i != size; i++) elements[i]=0;
            }

            ~Container() { delete[] elements; }
    }

    Мы считаем, что удержание ресурса - это инвариант класса, и привязываем время владения ресурса ко времени жизни объекта класса. Такой подход к управлению ресурсами называется RAII (Resource Acquisition Is Initialization).
