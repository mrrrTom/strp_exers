    Как объявить функцию, которая принимает переменное количество аргументов?
    Технически существует несколько способов:
    1. Шаблон с переменным числом параметров
    2. initializer_list
    3. В конце списка аргументов поставить ...
    В этой заметки хотелось бы рассмотреть именно последний вариант - в конце
концов это старейший вариант, нужно проявить уважение.
    При чем он настолько старый, что старше, собственно, чем C++. Уже в C89
присутствует возможность работы с переменным числом аргументов функции,
обеспечиваемая заголовочным файлом <stdarg.h>, однако ещё до него (K&R pre-C89)
существовал <varargs.h>, который обеспечивал аналогичную функционалость [1].
```cpp
    #include <iostream>
    using namespace std;
    void f(int i ...) {
        cout << i << endl;
    }

    int main() {
        f(4);
        return 0;
    }
```
    Таким образом я определил функцию, в которую можно передать разное
    количество параметров:
    
```cpp
    f(1, 2, 'a', 0.2, "uuu");
```
    При чём разное количество параметров с разными типами, как видно на примере.
    При чем в данной функции первый параметр типа int - обязательный.
    Чтобы работать с этими параметрами, нужно подключить <cstdarg> и
    воспользоваться макросами оттуда: 
    va_list - список аргументов 
    va_arg - получить следующий элемент списка
    va_end - очистить аргументы (добавлять нужно, чтобы стек не поломался)

```cpp
    #include <iostream>
    #include <cstdarg>
    using namespace std;

    void f(int i ...) {
       va_list pars;
       va_start(pars, i);
       cout << i << endl;

       int j = va_args(pars, int);
       cout << j << endl;

       char k = va_arg(pars, int);
       cout << k << endl;

       float t = va_arg(pars, double);
       cout << t << endl;

       char* s = va_arg(pars, char*);
       cout << s << endl;

       va_end(pars);
    }

    int main() {
       f(1, 2, 'a', 0.2, "uuu");
       return 0;
    }
```
    Примечательно, что, например, char передаётся как int из-за того, что
    тип аргумента не был объявлен нормально, соответственно привычная проверка
    типов отменяется. Учитывая это, таких функций следуюет избегать [2].
    Избегать не получается, когда приходится работать с Сишными старыми
    функциями, которые такими штуками балуются. Но gh говорит мне, что
    такие функции пишутся и без явной необходимости. Зачем?
    Частый вот такой вариант:

```cpp
void print(const char* format ...) {
    //smth
}
```
    И используют такие функции, например, чтобы пользовательские аргументы
    залогировать. Такое мы осуждаем. Чтобы было чуть больше похоже на
    язык со строгой типизацией:

```cpp
void print(const char* format, const vector<string>& args) {
    //тут, если нужно мы можем и проверить количество и валидность аргументов
}

//если необходимо, то мы можем добавить функцию, чтобы упаковать аргументы в контейнер

```
